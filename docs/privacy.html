Privacy Policy

Last updated: October 2026

Personal Assistant is a single-user project I built and run for my own personal use. It is not offered to the public, and no one other than me authorizes it against my own Google account.

What data it accesses

With my own Google account authorization, the application can read, search, and send email via the Gmail API, and read and modify spreadsheets via the Google Sheets API, strictly to carry out tasks I ask of it.

How data is used and stored

Data retrieved from Gmail or Sheets is used only to generate a response to my own request, within my own private deployment of this application. It is not sold, shared with third parties, or used for advertising. OAuth tokens are stored only within my own private cloud infrastructure, never shared externally.

Third-party access

No one other than me has access to this deployment or the data it processes.
